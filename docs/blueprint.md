# **App Name**: CultivaColombia

## Core Features:

- Interactive Crop Map: Interactive map displaying ideal crops by agroclimatic zone, classified by cultivation difficulty.
- Interactive Technical Sheets: Interactive technical sheets for each crop, including descriptions, life cycle, requirements, planting guides, and cost estimates.
- Personalized Monitoring: Personalized dashboard for registered users to monitor added crops with reminders and note-taking.
- AI Plant Detection: AI-powered tool to detect plant species and health status from uploaded images.
- Interactive Crop Recommendation Test: Crop Recommendation Test, a form that guides the user to find a crop to start planting based on the user's personal context.

## Style Guidelines:

- Primary color: A vibrant green (#6AB04C) to evoke growth, nature, and health.
- Background color: A light, desaturated green (#E5E8E3) to provide a natural, calm backdrop.
- Accent color: An earthy yellow (#EAB543) to highlight interactive elements and important information.
- Body and headline font: 'PT Sans', a humanist sans-serif that combines a modern look and a little warmth.
- Use clear and representative icons for each crop type, planting method, and requirement.
- Clean and intuitive layout with clear visual hierarchy, emphasizing educational content and interactive features.
- Subtle animations for transitions and feedback to enhance user experience.
